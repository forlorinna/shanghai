# V0.2.0 开发进度

V0.2 在原 Godot 工程内改造，保留 8.158 km² OSM 城区、140 个分块、原角色与驾驶输入、任务、轮渡、隧道、触屏和本地存档。V0.1 地图源数据和 Android 包保存在工作区。

| 交付项 | 当前版本 |
| --- | --- |
| 白天和雨夜街景 | 陆家嘴、上海中心周边和外滩增加街道设施、铺装、磨损标线、外墙层次和灯光。可在地图中按原入口抵达 |
| 渲染 | PBR、ACES、HDR 天空、动态太阳、五档画质、独立项目和自适应分辨率 |
| 地标 | 八栋或座地标的近远 GLB，地标变换与原碰撞相接，重要夜景以发光材质控制 |
| 汽车和人物 | 曲面车身、车灯、轮毂、车牌、雨刷、喷水、服装纹理、面部与步态重做 |
| 水体与降雨 | 多向波浪、水滴波纹、岸边扰动、雨滴、湿路和局部灯光。高档支持岸边镜像视图 |
| 摄影 | 独立暂停摄影模式、航拍、焦段、时间天气、色调和离屏高清截图 |
| 发布 | Android ARM64，包名 com.shanghai.openworld、versionCode 2，保留 V0.1 签名证书 |

当前走路、驾驶和雨夜的实拍画面仍能看出程序化城市的构造。继续扩展的主要项目为外滩历史立面手工细化、上海道路设施覆盖、更多真实车辆内饰、完整角色蒙皮动画、静态全局光照贴图，以及 Android 设备调优。高度缺失的 OSM 普通楼宇仍使用原版估算规则。详见渲染说明与测试报告。
